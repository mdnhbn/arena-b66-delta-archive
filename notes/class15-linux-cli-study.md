পূর্বপ্রস্তুতি

মূল ধারণা
- pwd: বর্তমান directory; ls বা ls -la: ফাইল এবং hidden file দেখা।
- cd: directory বদলানো; absolute path ও relative path-এর পার্থক্য বুঝুন।
- mkdir: directory তৈরি; cp: কপি; mv: ফাইলের নাম বা অবস্থান বদলানো।
- cat: পাঠ্য ফাইল দেখা; wc -l: লাইন গণনা।
- chmod: অনুমতি পরিবর্তন; owner, group ও others-এর অনুমতি আলাদা।
- command-এর options ও arguments বুঝে ব্যবহার করুন; নিজের system-এর man pages দেখুন।

অনুশীলন
ডকুমেন্ট ট্যাবের class15-linux-cli-practice.txt ডাউনলোড করে কমান্ডগুলো একটির পর একটি পড়ে চালান। প্রতিটি ধাপে pwd, ls এবং সংশ্লিষ্ট ফাইলের ফল লিখে রাখুন। অনুশীলনে administrator privilege বা ফাইল মুছে দেওয়ার কমান্ড প্রয়োজন নেই।
