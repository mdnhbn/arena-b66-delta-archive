# ক্লাস ২৩ — Recon: সংক্ষিপ্ত নোট

তারিখ: ৯ অক্টোবর ২০২৬, শুক্রবার।

লাইভের নির্বাচিত অংশে ffuf দিয়ে directory discovery ও SecLists wordlist ব্যবহার দেখা গেছে। পূর্ণ রেকর্ডিং এবং প্রকৃত সময় এখনও যাচাই বাকি।

কোর্স গাইডে সফটওয়্যার প্রস্তুতি, উন্মুক্ত তথ্য সংগ্রহ, সাবডোমেইন খোঁজা, সচল সার্ভিস শনাক্ত, প্রযুক্তি চেনা, ডিরেক্টরি ও URL অনুসন্ধান, JavaScript বিশ্লেষণ, parameter খোঁজা এবং vulnerability scanning-এর ধাপ আছে। গাইডের তালিকা থেকে পুরো ক্লাসের অগ্রগতি নির্ধারণ করা হয়নি। Directory discovery অংশে ffuf ছাড়াও Feroxbuster ও dirsearch উল্লেখ আছে; এই দুই টুলের ব্যবহার আজকের ভিডিও থেকে যাচাই হয়নি।
