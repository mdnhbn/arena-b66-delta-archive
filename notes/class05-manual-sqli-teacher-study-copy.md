# Manual SQLI — শিক্ষক-ডকের সম্পাদিত পাঠসংস্করণ

কোন সংস্করণটি পড়ছেন
ক্লাস ০৫-এর সঙ্গে সম্পর্কিত শিক্ষক-দেওয়া Manual SQLI Google Docs-এর সম্পাদিত পাঠসংস্করণ এটি। মূল নথির তৃতীয় পক্ষের domain, admin URL এবং username/password-সদৃশ ক্ষেত্র প্রকাশ করা হয়নি। মূল document-এর হুবহু PDF বা screenshot হিসেবে এই ফাইলকে ব্যবহার করবেন না।

নথিতে পাওয়া বিষয়
URL/URI-এর পরিভাষা, URL-এর path ও query parameter আলাদা করে দেখা, input যাচাইয়ের প্রয়োজন এবং database-কেন্দ্রিক পরীক্ষার ধাপের একটি সংক্ষিপ্ত outline আছে। এই outline নিজে কোনো vulnerability প্রমাণ করে না। পূর্ণ ব্যাখ্যা ও সীমাবদ্ধতার জন্য ক্লাস ০৫-এর ভিডিও ও পূর্ণ অডিও-ভিত্তিক পাঠনোট দেখুন।

শিক্ষক-দেওয়া টুলের সূত্র
Link Gopher-এর Chrome ও Firefox-এর অফিসিয়াল store link ছিল। ক্লাস ০৫-এর টুলস ট্যাবে তার download ও setup আগেই সংরক্ষিত আছে। নিজের/অনুমোদিত app-এর link inventory বোঝার কাজে ব্যবহার করুন।

আর্কাইভের যোগ করা অনুশীলন
নিজের একটি URL-এর scheme, host, path এবং query আলাদা করে লিখুন। Browser request-এর input কীভাবে নিজের server handler-এ পৌঁছায় তা ব্যাখ্যা করুন। কোনো বাস্তব তৃতীয় পক্ষের তথ্য সংগ্রহ বা login পরীক্ষা এই অনুশীলনের অংশ নয়।
