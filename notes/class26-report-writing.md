# ক্লাস ২৬ — Report Writing: রিসোর্স সূচি ও বিশ্লেষণের অবস্থা

ক্লাস ২৬ — Report Writing · রবিবার, ১৮ অক্টোবর ২০২৬

বর্তমানে সংরক্ষিত তথ্য
প্রশিক্ষক Syed Sakib Alam Mubin-এর Facebook পোস্টে Report Writing বিষয় নিশ্চিত। দুটি replay পাওয়া গেছে: প্রথম অংশ ২২:৩১, পরের অংশ ১:১৩:০৮। পরের অংশের প্রকৃত player duration ৪৩৮৮.১ সেকেন্ড ও resolution 1280×720; playback এগোতে দেখা হয়েছে। প্রথম অংশের দৈর্ঘ্য group player-এর display অনুযায়ী। এগুলো অবিচ্ছিন্ন পূর্ণ ক্লাসের সব মিনিট—এমন নিশ্চয়তা দেওয়া হচ্ছে না।

সংরক্ষণের অবস্থা
মূল দুই ভিডিওর লিংক নিচে আছে। YouTube/Dailymotion mirror এখনো যোগ হয়নি; সাইটের player-ready বা upload-processing হিসেবে দেখানো হয়নি। পূর্ণ অডিও NotebookLM-এ বিশ্লেষণ, বিস্তারিত শিক্ষকভিত্তিক পাঠনোট, নির্দিষ্ট homework ও deadline যাচাই বাকি। এই প্রাথমিক সূচিকে পূর্ণ ভিডিও-সারাংশ হিসেবে ব্যবহার করবেন না।

রিপোর্টের রেফারেন্স লাইব্রেরি
গ্রুপ চ্যাটে PentestReports.com লিংক শেয়ার হয়েছে। সাইটটি public penetration-test report, template ও অন্যান্য security resource-এর সূচি হিসেবে দেখা গেছে। নিচের রিসোর্স কার্ড থেকে পরিষ্কার মূল লিংক খুলতে পারবেন; Facebook tracking link সংরক্ষণ করা হয়নি। এই পর্যায়ে লিংকটি শিক্ষক সরাসরি দিয়েছেন—এমন attribution যাচাই হয়নি। অন্য প্রতিষ্ঠানের report নিজের করা কাজ বা নিজের client-এর তথ্য হিসেবে ব্যবহার করবেন না। মূল report-এর ব্যবহারবিধি ও লেখকের attribution দেখুন।

নিজস্ব সহায়ক worksheet
ডকুমেন্ট ট্যাবে Scope → Evidence → Impact → Remediation → Retest সাজানোর একটি ডাউনলোডযোগ্য Markdown worksheet রাখা হয়েছে। এটি আর্কাইভের নিজস্ব সহায়ক সংযোজন, শিক্ষকপ্রদত্ত মূল document নয়। কোনো live client data বা private report এতে দেওয়া হয়নি।
