# ক্লাস ২৬ — শিক্ষকের হোমওয়ার্ক: একটি বাগ রিপোর্ট

ক্লাস: ১৮ অক্টোবর ২০২৬, Report Writing।

শিক্ষকের নির্দেশ: নিজেদের আগের homework/practice-এর একটি finding বেছে একটি নির্দিষ্ট bug report তৈরি করে submit করতে হবে। জমার সংখ্যা: একটি report। নিজের মতো report design আগে থেকে প্রস্তুত রাখতে বলেছেন। শুধু scanner-এর raw report-কে মূল report হিসেবে পাঠাবেন না; ফল যাচাই করে নিজের ব্যাখ্যা লিখুন।

নির্দিষ্ট deadline, submission channel বা বাধ্যতামূলক file extension এই পর্যালোচিত অডিওতে নিশ্চিত হয়নি। শিক্ষক demo report দেবেন বলেছেন; মূল downloadable PDF এখনো পাওয়া যায়নি।

আর্কাইভের সহায়ক checklist — শিক্ষক-নির্ধারিত অতিরিক্ত grading rule নয়:
- নিজের বা অনুমতিপ্রাপ্ত lab-এর একটি finding ব্যবহার করুন।
- Title, description, evidence, environment, impact ও remediation সাজান।
- Scanner output ও AI-এর বক্তব্যের সত্যতা যাচাই করুন।
- Public কপিতে ব্যক্তিগত তথ্য, credential ও client secret ঢেকে দিন।
- পাশের Report Writing Worksheet নিজের কাজ সাজাতে ব্যবহার করতে পারেন; এটি শিক্ষকপ্রদত্ত মূল demo নয়।

উৎসের সীমা: দ্বিতীয় অংশের সম্পূর্ণ ৭৩:০৮ অডিও ও তার শেষের পুনরাবৃত্ত homework নির্দেশ থেকে যাচাই। প্রথম অংশের পূর্ণ অডিও বিশ্লেষণ এখনো হয়নি।
