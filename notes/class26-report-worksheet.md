# Report Writing — অনুশীলনের worksheet

ক্লাস ২৬ · ১৮ অক্টোবর ২০২৬। আর্কাইভের নিজস্ব সহায়ক template; শিক্ষকপ্রদত্ত file নয়।

## পরিচিতি ও scope
- Report title / version / date:
- অনুমোদিত test environment ও scope:
- পরীক্ষার সীমা ও বাদ দেওয়া অংশ:

## সংক্ষিপ্ত ফল
- কী পর্যবেক্ষণ করা হয়েছে:
- প্রভাব ও কার জন্য প্রাসঙ্গিক:
- Severity ও তার যুক্তি:

## Finding-এর প্রমাণ
- Finding ID ও পরিষ্কার শিরোনাম:
- প্রত্যাশিত ও পর্যবেক্ষিত আচরণ:
- নিজের/অনুমোদিত lab-এ পুনরুৎপাদনের পর্যবেক্ষণ:
- ব্যক্তিগত তথ্য মুছে screenshot / log reference:
- নিশ্চিত, সন্দেহজনক ও অযাচাইকৃত ফল আলাদা করা:

## প্রতিকার ও retest
- মূল কারণ ও প্রস্তাবিত সংশোধন:
- দায়িত্ব ও অগ্রাধিকার:
- Retest date / version / ফল:
- অবশিষ্ট সীমাবদ্ধতা:

Report-এ password, token, ব্যক্তিগত তথ্য বা অপ্রয়োজনীয় raw data রাখবেন না। Sample report-কে নিজের সম্পন্ন কাজ বলে উপস্থাপন করবেন না।
