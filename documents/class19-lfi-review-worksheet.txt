CLASS 19 — FILE INCLUSION REVIEW WORKSHEET
Prepared: 2026-10-11. Related class: 2026-09-25.
Own supplementary worksheet; not the instructor's original lab package.

Use only your own training application or an explicitly authorized lab.
No executable, remote target, payload or credential is bundled here.

1. Draw: request input -> identifier validation -> fixed template map -> file operation.
2. Identify whether the operation reads content or evaluates included code.
3. List the allowed template identifiers; avoid accepting arbitrary filesystem paths.
4. Record expected behavior for an allowed identifier, unknown identifier,
   missing value, empty value and non-string input. Unknown values must be rejected.
5. Review application file permissions and whether uploaded files can execute.
6. Record actual results, environment, evidence and remediation separately.
7. Distinguish observed LFI from demonstrated code execution; do not assume RCE.
