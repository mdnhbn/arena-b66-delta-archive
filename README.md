# Arena Web Security — B66 Delta Archive

[Public website](https://arena-b66-delta-archive.vercel.app) · [Chronological document](CATALOG.md) · [Archive status](ARCHIVE.md)

A Bengali static learning archive with categories, search, chronological sorting, resource details, related topics and YouTube embeds. Source records are stored in `data.json`. Main-branch updates deploy automatically to Vercel.

## Current status

148 collected entries; 22 dated recording posts with source Drive links. Some post dates and full text still require verification. The record numbers refer to collected recordings, not official class numbers.

Two existing instructor YouTube links are included. The homework-panel guide has been uploaded as video `oka_NMsPt-Y`; YouTube reports SD processing delayed by up to a few hours, the watch page shows Unlisted, but playback is still pending. The initial file-path upload error was resolved. Keep local video copies until upload, processing and playback are verified.

The archive is incomplete; do not present it as a complete verified course export.

## Editing

Update an entry's `youtubeId` only after verifying its matching class, visibility and playback. Unknown dates remain null. Do not store account credentials or access tokens in this public repository.

This website has no build dependencies. Serve the repository root as static files.
